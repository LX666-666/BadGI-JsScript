# 02. 全局函数

## 方法表

| 方法 | 返回 | 说明 |
|---|---|---|
| `sleep(milliseconds)` | `Promise<void>` | 可取消延时 |
| `getVersion()` | `string` | BetterGI 版本 |
| `keyDown(key)` / `keyUp(key)` / `keyPress(key)` | `void` | 虚拟键输入 |
| `setGameMetrics(width, height, dpi = 1)` | `void` | 设置脚本坐标系；分辨率必须 16:9 |
| `getGameMetrics()` | `double[]` | `[width, height, dpi]` |
| `moveMouseBy(x, y)` | `void` | 相对移动 |
| `moveMouseTo(x, y)` | `void` | 移动到脚本坐标 |
| `click(x, y)` | `void` | 移动并左击 |
| `leftButtonClick/Down/Up()` | `void` | 左键操作 |
| `rightButtonClick/Down/Up()` | `void` | 右键操作 |
| `middleButtonClick/Down/Up()` | `void` | 中键操作 |
| `verticalScroll(clicks)` | `void` | 垂直滚轮 |
| `captureGameRegion()` | `ImageRegion` | 当前游戏画面 |
| `getAvatars()` | `string[]` | 当前队伍角色名；识别失败为空数组 |
| `inputText(text)` | `void` | 通过剪贴板和 Ctrl+V 输入文本 |

## 键名

参数必须能转换为 Windows Virtual Key，例如：

```js
keyPress("VKF");
keyDown("VKW");
await sleep(300);
keyUp("VKW");
```

## 坐标与截图

```js
setGameMetrics(1920, 1080);
click(960, 540);

const image = captureGameRegion();
try {
    log.info("截图尺寸: {0}x{1}", image.Width, image.Height);
} finally {
    image.dispose();
}
```

## 注意

- `moveMouseTo` 会检查坐标是否位于设定的游戏范围。
- `setGameMetrics` 的宽高不满足 16:9 会抛出异常。
- `inputText` 会临时写入系统剪贴板；源码当前没有可靠恢复原剪贴板内容。
