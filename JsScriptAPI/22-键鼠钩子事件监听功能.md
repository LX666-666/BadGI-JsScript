# JavaScript脚本开发 - 键鼠钩子事件监听功能

## 概述

BGI（BetterGenshinImpact）通过 `KeyMouseHook` 类为JavaScript脚本提供了完整的全局键盘和鼠标事件监听功能。开发者可以注册回调函数来监听用户的键盘按键、鼠标点击、鼠标移动和滚轮操作，实现交互式脚本控制。

**相关代码位置**: `BetterGenshinImpact\Core\Script\Dependence\KeyMouseHook.cs:12-420`
**引擎注册位置**: `BetterGenshinImpact\Core\Script\EngineExtend.cs:76`

**主要特性**:
- ✅ 全局键盘事件监听（按下/释放）
- ✅ 全局鼠标事件监听（点击/移动/滚轮）
- ✅ 自动坐标转换（全局坐标→游戏窗口局部坐标）
- ✅ 鼠标移动事件间隔控制（避免过度触发）
- ✅ 异常安全处理（自动清理回调防止脚本崩溃）
- ✅ 资源管理（Dispose模式释放钩子资源）

## 键盘事件监听

### KeyData vs KeyCode 详解

BGI的键盘事件系统提供了两种键盘数据获取方式：**KeyCode**（按键码）和**KeyData**（完整按键数据）。理解两者的区别对于正确处理键盘事件至关重要。

**代码位置**: `KeyMouseHook.cs:17-20, 116-185` (两种回调列表和事件处理逻辑)

#### KeyCode（按键码）- 默认模式

**定义**: 仅返回被按下的主键，不包含修饰键（Ctrl、Shift、Alt）信息。

**特点**:
- ✅ 简单直观，适合大多数场景
- ✅ 返回值清晰，如 `"F1"`, `"A"`, `"Escape"`
- ❌ 无法区分是否同时按下了修饰键

**使用场景**:
- 单键快捷键检测（F1、F2、ESC等）
- 简单的按键响应
- 不需要组合键的场景

```javascript
const hook = new KeyMouseHook();

// 默认使用KeyCode模式（useCodeOnly=true）
hook.OnKeyDown((keyCode) => {
    log.info(`按键: ${keyCode}`);
    // 输出示例：
    // 按下 F1 → "F1"
    // 按下 A → "A"
    // 按下 Ctrl+A → "A" （只显示A，不显示Ctrl）
});
```

#### KeyData（完整按键数据）- 高级模式

**定义**: 返回完整的按键信息，包括主键和所有修饰键的组合。

**特点**:
- ✅ 包含修饰键信息（Ctrl、Shift、Alt）
- ✅ 可以准确检测组合键
- ⚠️ 返回值较复杂，需要解析

**使用场景**:
- 组合键检测（Ctrl+C、Shift+F1等）
- 需要区分单键和组合键的场景
- 高级键盘事件处理

```javascript
const hook = new KeyMouseHook();

// 使用KeyData模式（useCodeOnly=false）
hook.OnKeyDown((keyData) => {
    log.info(`完整按键数据: ${keyData}`);
    // 输出示例：
    // 按下 F1 → "F1"
    // 按下 A → "A"
    // 按下 Ctrl+A → "Control, A"
    // 按下 Ctrl+Shift+A → "Control, Shift, A"
}, false);
```

#### 对比表格

| 特性 | KeyCode | KeyData |
|------|---------|---------|
| **默认值** | ✅ 是（useCodeOnly=true） | ❌ 否（需设置useCodeOnly=false） |
| **修饰键** | ❌ 不包含 | ✅ 包含 |
| **返回格式** | 单个按键名 | 逗号分隔的按键列表 |
| **示例（按F1）** | `"F1"` | `"F1"` |
| **示例（按Ctrl+F1）** | `"F1"` | `"Control, F1"` |
| **示例（按Ctrl+Shift+A）** | `"A"` | `"Control, Shift, A"` |
| **适用场景** | 简单按键检测 | 组合键检测 |
| **解析难度** | 简单 | 需要字符串解析 |

#### 实际应用示例

**场景1：简单快捷键（使用KeyCode）**

```javascript
const hook = new KeyMouseHook();

hook.OnKeyDown((keyCode) => {
    switch (keyCode) {
        case 'F1':
            log.info('F1 - 显示帮助');
            break;
        case 'F2':
            log.info('F2 - 开始录制');
            break;
        case 'Escape':
            log.info('ESC - 退出脚本');
            hook.Dispose();
            break;
    }
});
```

**场景2：组合键检测（使用KeyData）**

```javascript
const hook = new KeyMouseHook();

hook.OnKeyDown((keyData) => {
    // 检测 Ctrl+C
    if (keyData === 'Control, C') {
        log.info('检测到 Ctrl+C - 复制操作');
    }

    // 检测 Ctrl+Shift+S
    if (keyData === 'Control, Shift, S') {
        log.info('检测到 Ctrl+Shift+S - 另存为');
    }

    // 检测 Alt+F4
    if (keyData === 'Alt, F4') {
        log.info('检测到 Alt+F4 - 关闭窗口');
    }
}, false);  // 重要：设置为false以获取KeyData
```

**场景3：混合使用（推荐模式）**

```javascript
const hook = new KeyMouseHook();

// 方法1：使用KeyCode + 手动跟踪修饰键状态
let ctrlPressed = false;
let shiftPressed = false;

hook.OnKeyDown((keyCode) => {
    // 跟踪修饰键状态
    if (keyCode === 'ControlKey') {
        ctrlPressed = true;
        return;
    }
    if (keyCode === 'ShiftKey') {
        shiftPressed = true;
        return;
    }

    // 检测组合键
    if (ctrlPressed && shiftPressed && keyCode === 'S') {
        log.info('检测到 Ctrl+Shift+S');
    } else if (ctrlPressed && keyCode === 'C') {
        log.info('检测到 Ctrl+C');
    } else if (keyCode === 'F1') {
        log.info('检测到 F1');
    }
});

hook.OnKeyUp((keyCode) => {
    // 释放修饰键状态
    if (keyCode === 'ControlKey') {
        ctrlPressed = false;
    }
    if (keyCode === 'ShiftKey') {
        shiftPressed = false;
    }
});
```

#### KeyData字符串解析工具

```javascript
// 解析KeyData字符串的辅助函数
function parseKeyData(keyData) {
    const keys = keyData.split(', ').map(k => k.trim());

    return {
        hasCtrl: keys.includes('Control'),
        hasShift: keys.includes('Shift'),
        hasAlt: keys.includes('Alt'),
        mainKey: keys[keys.length - 1],  // 最后一个是主键
        allKeys: keys
    };
}

// 使用示例
const hook = new KeyMouseHook();

hook.OnKeyDown((keyData) => {
    const parsed = parseKeyData(keyData);

    log.info(`主键: ${parsed.mainKey}`);
    log.info(`Ctrl: ${parsed.hasCtrl}, Shift: ${parsed.hasShift}, Alt: ${parsed.hasAlt}`);

    // 检测特定组合
    if (parsed.hasCtrl && parsed.hasShift && parsed.mainKey === 'S') {
        log.info('检测到 Ctrl+Shift+S');
    }
}, false);
```

#### 常见修饰键名称

| 修饰键 | KeyCode名称 | KeyData中的名称 |
|--------|------------|----------------|
| 左Ctrl | `ControlKey` | `Control` |
| 右Ctrl | `ControlKey` | `Control` |
| 左Shift | `ShiftKey` | `Shift` |
| 右Shift | `ShiftKey` | `Shift` |
| 左Alt | `Menu` | `Alt` |
| 右Alt | `Menu` | `Alt` |
| Windows键 | `LWin` / `RWin` | `LWin` / `RWin` |

#### 选择建议

**使用KeyCode的情况**:
- ✅ 只需要检测单个按键（F1、ESC、数字键等）
- ✅ 不需要区分是否按下修饰键
- ✅ 追求代码简洁性

**使用KeyData的情况**:
- ✅ 需要检测组合键（Ctrl+C、Shift+F1等）
- ✅ 需要区分单键和组合键
- ✅ 实现复杂的快捷键系统

**混合使用的情况**:
- ✅ 既有单键又有组合键的场景
- ✅ 需要精确控制修饰键状态
- ✅ 追求最佳性能和灵活性

## 键盘事件监听方法

### OnKeyDown(callback, useCodeOnly)

注册键盘按下事件的回调函数。

```javascript
// 监听键盘按下事件（默认仅返回KeyCode）
const hook = new KeyMouseHook();
hook.OnKeyDown((keyCode) => {
    log.info(`键盘按下: ${keyCode}`);

    if (keyCode === 'F1') {
        log.info('F1功能键被按下');
    } else if (keyCode === 'Escape') {
        log.info('ESC键被按下，准备退出');
    }
});
```

```javascript
// 监听键盘按下事件（获取完整KeyData）
const hook = new KeyMouseHook();
hook.OnKeyDown((keyData) => {
    log.info(`键盘按下（完整数据）: ${keyData}`);
    // keyData 包含修饰键信息，如 "Control, Shift, A"
}, false); // useCodeOnly=false 获取完整KeyData
```

**参数**:
- `callback` (Function): 回调函数，接收参数 `(keyCode: string)` 或 `(keyData: string)`
- `useCodeOnly` (boolean, 可选): 是否仅返回KeyCode，默认 `true`
  - `true`: 回调参数为KeyCode字符串（如 `"F1"`, `"Escape"`, `"A"`）
  - `false`: 回调参数为KeyData字符串（包含修饰键信息，如 `"Control, A"`）

**代码位置**: `KeyMouseHook.cs:306-312`

## 鼠标事件监听

### OnMouseDown(callback)

注册鼠标按下事件的回调函数。

```javascript
// 监听鼠标按下事件
const hook = new KeyMouseHook();
hook.OnMouseDown((button, localX, localY) => {
    log.info(`鼠标按下: ${button} 在游戏坐标 (${localX}, ${localY})`);

    if (button === 'Left') {
        log.info('左键点击');
    } else if (button === 'Right') {
        log.info('右键点击');
    }
});
```

**参数**:
- `callback` (Function): 回调函数，接收参数：
  - `button` (string): 鼠标按钮名称（`"Left"`, `"Right"`, `"Middle"`, `"XButton1"`, `"XButton2"`）
  - `localX` (number): 游戏窗口内的X坐标（已自动转换）
  - `localY` (number): 游戏窗口内的Y坐标（已自动转换）

**重要说明**:
- 坐标已自动转换为游戏窗口内的局部坐标，可直接用于 `click(localX, localY)` 等方法
- 如果坐标转换失败，localX和localY均为 `-1`

**代码位置**: `KeyMouseHook.cs:327-330`, 坐标转换: `72-111`

## 资源管理方法

### RemoveAllListeners()

移除所有已注册的事件监听器，但不释放钩子资源。

```javascript
const hook = new KeyMouseHook();
hook.OnKeyDown((key) => log.info(key));
hook.OnMouseDown((btn, x, y) => log.info(`${btn} at ${x},${y}`));

// 移除所有监听器
hook.RemoveAllListeners();

// 可以继续注册新的监听器
hook.OnKeyDown((key) => log.info(`新监听器: ${key}`));
```

**代码位置**: `KeyMouseHook.cs:354-367`

---

### Dispose()

释放所有钩子资源，包括移除事件监听器和注销全局钩子。

```javascript
const hook = new KeyMouseHook();
hook.OnKeyDown((key) => log.info(key));

// 脚本结束前释放资源
hook.Dispose();
```

**⚠️ 重要提示**:
- **必须在脚本结束前调用** `Dispose()` 方法释放资源
- 如果脚本异常终止未调用Dispose()，会导致全局钩子泄露
- 当回调函数抛出异常时，系统会自动调用Dispose()并清理所有监听器

**代码位置**: `KeyMouseHook.cs:369-419`

## 使用示例

### 示例1：快捷键控制脚本

```javascript
// 使用F1启动/停止脚本
let isRunning = false;
const hook = new KeyMouseHook();

hook.OnKeyDown((keyCode) => {
    if (keyCode === 'F1') {
        isRunning = !isRunning;
        if (isRunning) {
            log.info('🚀 脚本已启动');
        } else {
            log.info('⏸️ 脚本已暂停');
        }
    } else if (keyCode === 'Escape') {
        log.info('🛑 脚本终止');
        hook.Dispose();
        return;
    }
});

// 主循环
while (true) {
    if (isRunning) {
        // 执行脚本逻辑
        await performTask();
    }
    await sleep(100);
}
```

## 最佳实践

### 1. 资源释放管理

✅ **推荐做法**:
```javascript
const hook = new KeyMouseHook();
try {
    hook.OnKeyDown((key) => {
        // 处理逻辑
    });

    // 执行主要任务
    await mainTask();

} finally {
    // 确保资源释放
    hook.Dispose();
}
```

❌ **错误做法**:
```javascript
const hook = new KeyMouseHook();
hook.OnKeyDown((key) => { /* ... */ });
// 忘记调用 Dispose()，导致资源泄露
```

### 2. 异常处理

```javascript
const hook = new KeyMouseHook();

hook.OnKeyDown((keyCode) => {
    try {
        // 回调逻辑可能抛出异常
        if (keyCode === 'F1') {
            performRiskyOperation();
        }
    } catch (error) {
        log.error(`处理按键事件时出错: ${error}`);
        // 不要在回调中抛出未捕获的异常
    }
});
```

### 3. 避免回调函数中的长时间操作

❌ **错误做法**:
```javascript
hook.OnKeyDown((key) => {
    // 长时间阻塞操作会影响事件处理
    await sleep(5000); // ❌ 不要在回调中使用sleep
    performHeavyTask(); // ❌ 不要执行耗时操作
});
```

✅ **推荐做法**:
```javascript
let taskTriggered = false;

hook.OnKeyDown((key) => {
    if (key === 'F1') {
        taskTriggered = true; // 仅设置标志
    }
});

// 在主循环中处理
while (true) {
    if (taskTriggered) {
        taskTriggered = false;
        await performHeavyTask(); // 在主循环中执行耗时操作
    }
    await sleep(100);
}
```

### 4. 鼠标移动事件间隔设置

根据实际需求选择合适的interval值：

```javascript
// 高精度轨迹记录（消耗资源多）
hook.OnMouseMove((x, y) => recordTrail(x, y), 50);

// 常规监控（推荐）
hook.OnMouseMove((x, y) => updatePosition(x, y), 200);

// 低频采样（节省资源）
hook.OnMouseMove((x, y) => logPosition(x, y), 1000);
```

### 5. 防止重复注册

❌ **错误做法**:
```javascript
while (true) {
    const hook = new KeyMouseHook(); // ❌ 循环中重复创建
    hook.OnKeyDown((key) => log.info(key));
    await sleep(1000);
}
```

✅ **推荐做法**:
```javascript
const hook = new KeyMouseHook(); // ✅ 只创建一次
hook.OnKeyDown((key) => log.info(key));

while (true) {
    // 执行其他逻辑
    await sleep(1000);
}

hook.Dispose(); // 退出时释放
```

## 注意事项

### ⚠️ 关键限制

1. **全局钩子资源**
   - KeyMouseHook 使用全局键鼠钩子，资源有限
   - **必须在脚本结束时调用 `Dispose()`** 释放资源
   - 未释放的钩子会导致系统资源泄露

2. **坐标转换依赖**
   - 鼠标坐标转换依赖 `TaskContext` 的初始化状态
   - 如果游戏窗口未正确识别，坐标可能为 `(-1, -1)`
   - 确保游戏窗口已正常捕获后再使用鼠标事件

3. **回调函数异常**
   - 如果回调函数抛出异常，系统会**自动调用 `Dispose()`** 清理所有监听器
   - 请在回调中妥善处理异常，避免意外中断

4. **线程安全**
   - 回调函数在全局钩子线程中执行
   - 避免在回调中进行复杂的异步操作或阻塞调用

### 🔒 安全限制

- 键盘事件会捕获**所有**键盘输入，包括系统快捷键
- 鼠标事件会捕获**所有**鼠标操作，包括系统界面操作
- 请勿滥用钩子功能监听用户隐私信息

### 📏 性能建议

- 鼠标移动事件触发频率极高，建议设置合理的 `interval` 值（推荐200ms以上）
- 避免在回调中执行耗时操作，建议使用标志位在主循环中处理
- 单个脚本不建议创建多个 `KeyMouseHook` 实例

## 错误处理

### 常见错误1：未释放资源

**错误现象**:
```
执行键盘按下事件回调时发生错误: ...，清除所有回调
如果此异常出现在JS脚本结束时，请在JS脚本结束前手动调用Dispose()方法
```

**解决方案**:
```javascript
const hook = new KeyMouseHook();
try {
    // 脚本逻辑
} finally {
    hook.Dispose(); // 确保释放
}
```

### 常见错误2：坐标转换失败

**错误现象**:
```
鼠标坐标始终为 (-1, -1)
```

**原因**:
- TaskContext未初始化
- 游戏窗口句柄无效
- 捕获区域未正确获取

**解决方案**:
```javascript
// 确保游戏已启动并正常捕获
await sleep(2000); // 等待游戏窗口初始化

const hook = new KeyMouseHook();
hook.OnMouseDown((button, x, y) => {
    if (x === -1 && y === -1) {
        log.warn('坐标转换失败，请检查游戏窗口状态');
        return;
    }
    log.info(`有效坐标: (${x}, ${y})`);
});
```
