# 00. 核对范围与调用约定

## 核对范围

本版覆盖 BetterGI 脚本引擎直接注入的对象、类型和全局函数，以及脚本开发中最常使用的图像识别类型。源码基准为仓库 `babalae/better-genshin-impact` 的 `main` 分支提交 `beb0a70f5bf145d593230cdf58b32babcd8dd792`。

## JavaScript 名称大小写

脚本引擎使用 `V8ScriptEngineFlags.UseCaseInsensitiveMemberBinding`，所以 C# 对象成员通常大小写不敏感：

```js
file.readTextSync("data/config.json");
file.ReadTextSync("data/config.json"); // 通常也可用
```

本文统一采用第一种写法。全局标识符由引擎逐个注入，建议严格使用：

```js
await sleep(1000);
const image = captureGameRegion();
```

## 异步规则

返回 C# `Task` / `Task<T>` 的方法可直接 `await`。同步方法不要为了“看起来统一”而滥用 `await`。

```js
const text = file.readTextSync("data/a.txt"); // 同步
const text2 = await file.readText("data/a.txt"); // 异步
const regions = locator.findAll(); // 同步
const waited = await locator.waitFor(5000); // 异步
```

## .NET 集合

常见返回值是 `.NET List<T>` 或数组：

```js
const regions = locator.findAll();
if (regions.Count > 0) {
    regions[0].click();
}

const names = Array.from(getAvatars());
```

## 资源释放

`ImageRegion`、临时 `Mat`、`KeyMouseHook` 等对象包含原生资源。使用 `try/finally`：

```js
const image = captureGameRegion();
try {
    // 识别、裁剪、OpenCV 处理
} finally {
    image.dispose();
}
```

## 不可用的常见运行时能力

```js
// 不要使用
fetch(url);
new XMLHttpRequest();
require("fs");
setTimeout(fn, 1000);
setInterval(fn, 1000);
```

替代方式：

- 网络：`http.request(...)`
- 延时：`await sleep(ms)`
- 模块：ES Module 的 `import` / `export`
- 文件：`file.*`
