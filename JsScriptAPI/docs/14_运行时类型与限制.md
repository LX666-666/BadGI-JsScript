# 14. 运行时类型与限制

## 注入对象

`keyMouseScript`、`pathingScript`、`genshin`、`log`、`file`、`http`、`notification`、`dispatcher`、`strategyFile`、`host`、`htmlMask`。

## 注入类型

`RealtimeTimer`、`SoloTask`、`AutoSkipConfig`、`CancellationTokenSource`、`CancellationToken`、`PostMessage`、`Mat`、`Point2f`、`RecognitionObject`、`DesktopRegion`、`GameCaptureRegion`、`ImageRegion`、`Region`、`CombatScenes`、`Avatar`、`ServerTime`、各自动任务参数类型、`KeyMouseHook`、`Task`、`BvPage`、`BvLocator`、`BvImage`。

## 运行环境

- 引擎：Microsoft ClearScript V8。
- 开启 Task/Promise 转换，可直接 `await` C# `Task`。
- 开启成员大小写不敏感。
- 支持 ESM；不支持 CommonJS。
- 脚本结束时引擎会被中断并释放。

## 不要假设存在

- DOM、`window`、`document`（仅 HTML 遮罩页面自身有浏览器环境）
- `fetch`、XHR、WebSocket
- Node.js `fs`、`path`、`process`、`Buffer`
- 浏览器计时器

## 异常处理模板

```js
(async function () {
    let image = null;
    try {
        image = captureGameRegion();
        // 主逻辑
    } catch (error) {
        log.error("执行失败: {0}", error && (error.Message || error.message || String(error)));
        notification.error("脚本执行失败");
        throw error;
    } finally {
        if (image) image.dispose();
    }
})();
```
